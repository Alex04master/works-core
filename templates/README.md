# Шаблоны заданий для works-core

Формат задания — JSON. Задание определяется массивом полей формы отчёта.

## Базовая структура

Каждое поле в массиве `форма` — объект:

```json
{
  "тип": "text",
  "ключ": "field_name",
  "вопрос": "Подпись поля для студента",
  "обязательно": true,
  "место": "подсказка внутри поля"
}
```

## Типы полей (встроенные в ядро)

| Тип | Описание | Доп. параметры |
|---|---|---|
| `static` | Заголовок-разделитель | `подсказка` — текст заголовка |
| `text` | Однострочный текст | `место` — placeholder |
| `textarea` | Многострочный текст | `строк` — высота (1-20), `место` |
| `number` | Число | `мин`, `макс`, `шаг`, `место` |
| `select` | Выпадающий список | `варианты` — массив строк |
| `radio` | Радиокнопки | `варианты` — массив строк |
| `checkbox` | Одна галочка | `подсказка` — подпись |
| `checkboxes` | Несколько галочек | `варианты` — массив строк |
| `file` | Загрузка файла | `accept` — mime-фильтр |
| `hidden` | Скрытое поле (данные виджетов, напр. план) | — |
| `shlei` | Таблица «Ведомость шлейфов» ОПС (5 колонок) | `строк` — строк по умолчанию (10) |
| `firmware` | Файлы прошивки прибора (несколько) | `лимит` — макс. файлов (по умолчанию 5) |
| `date` | Дата | `мин`, `макс` |
| `email` | Email | `место` |
| `tel` | Телефон | `место` |

## Пример задания

```json
{
  "id": "t1",
  "title": "Расчёт шлейфов",
  "описание": "## Задача\n\nРассчитать количество извещателей.",
  "форма": [
    {"тип": "static", "подсказка": "Параметры помещения"},
    {"тип": "number", "ключ": "width", "вопрос": "Ширина, м", "обязательно": true, "мин": 1},
    {"тип": "number", "ключ": "length", "вопрос": "Длина, м", "обязательно": true, "мин": 1},
    {"тип": "select", "ключ": "detector", "вопрос": "Тип извещателя",
     "варианты": ["ИП 212 (дымовой)", "ИП 101 (тепловой)"], "обязательно": true},
    {"тип": "number", "ключ": "count", "вопрос": "Количество, шт", "обязательно": true},
    {"тип": "textarea", "ключ": "note", "вопрос": "Обоснование", "строк": 4},
    {"тип": "file", "ключ": "scheme", "вопрос": "Схема расстановки"}
  ]
}
```

## Промпт для нейросети

При генерации заданий через нейросеть — придерживайтесь схемы выше.
Описание задания — Markdown (## заголовки, **жирный**, `код`, - списки).
Ключи полей — латиница без пробелов (width, detector_type, loops).
Количество полей — от 4 до 20 на одно задание.

# Идеи развития works-core

Сохранено 10.11.2026 (обсуждение «что можно ещё добавить»). Взятое в работу
помечается [x].

## Начать с этих

- [ ] **Режим «Контрольная/Экзамен»** — задание открывается только в окне
  времени, таймер на странице, по истечении сдача закрывается. Для
  УП-зачётов и проверочных.
- [x] **Автопроверка схемы (.vlx/.robxsim)** — сделано 11.11.2026 (модуль
  `schemacheck`): при сдаче файл схемы разбирается автоматически (компоненты,
  провода, скетчи); преподаватель задаёт эталон на странице задания
  («🔍 Эталон схемы»), отчёт с ✅/⚠/❌ виден на странице сдачи и у студента.
  Автобаллы в критериях — следующий шаг.
- [ ] **Разбор работы на табло** — на `/board` кнопка «показать работу
  студента»: сдача (отчёт + схема + баллы) красиво выводится на проектор.

## Студентам

- [ ] **Дедлайн-центр на «Моих заданиях»**: «до сдачи 2 дня — 2 задания»,
  сортировка по срокам, красное/жёлтое.
- [ ] **Серверные черновики отчёта** — автосохранение текстовых полей
  (сейчас черновик только у схемы в браузере).
- [ ] **Комментарий преподавателя по каждому критерию** (не только общий
  вердикт).
- [ ] **Показ эталона после принятия** — преподаватель включает по заданию.
- [ ] **«Задать вопрос по заданию»** — форма у задания → в панель
  преподавателя (частный случай баг-репорта, но про задание).

## Преподавателю

- [ ] **Живая лента класса**: кто на каком задании / в симуляторе / что
  сдало только что.
- [ ] **Массовые вердикты**: галочками несколько сдач → шаблон ответа →
  всем разом.
- [ ] **Сравнение версий сдачи** — diff текста двух версий.
- [ ] **Варианты заданий** — 2–3 варианта параметров, раздача по бригаде;
  синергия с антиплагиатом.
- [ ] **QR-код на табло** — студент сканирует камерой → открыл задание.
- [ ] **Сводки по курсу**: средний балл, гистограмма, «не сдали N человек».

## Служебное

- [ ] **Бэкап по расписанию** (раз в час) + кнопка «скачать последний».
- [ ] **Страница здоровья** `/_health`: сервер / симулятор / диск / входы.
- [ ] **Сброс пароля/сессии студента** преподавателем из панели.

## Известные, не чиним (решено)

- Краш вкладки симулятора на электронной доске («На сайте возникли
  неполадки») — только на доске, студенческие ПК работают. Обход: на доске
  демонстрировать симулятор отдельной вкладкой («↗ Открыть симулятор»).
